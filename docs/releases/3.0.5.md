# oh-my-multica v3.0.5

A fix release for Reviewer submits that hit Multica's 8KB issue-metadata limit.

## Behavior to know

- **Every metadata write shares one 8KB budget.** When the platform rejects a write at the limit, OMAC first applies the
  recoverable reductions, then moves inline `delivery_identity`, `reviewer_run_baseline` and `worker_handoff` to immutable
  attachments. If there is still no room it raises a named error; nothing is silently dropped.
- **A Reviewer submit the platform rejects is a named, recoverable block** (`reviewer-submit-rejected-by-platform`) instead of
  spending the no-submit budget. Clear it with the printed `omac node retry <manifest> <node> --stage review`.
- No new configuration; JSON fields and exit codes are unchanged.
