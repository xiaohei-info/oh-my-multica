# oh-my-multica v3.0.1

A fix release: manifest sync is quiet when nothing changed, and a stuck sync stops the loop.

## Behavior to know

- **A tick that changes nothing no longer commits.** The reconcile-audit schedule is host-local runtime data outside git;
  only business state is committed and pushed. A lost file forces one early full scan. The old `reconcile_audit` field is
  dropped on load and removed from git on the next save.
- **A stuck git sync stops `dag run`.** Sync failures name their step (`rebase_not_started`, `rebase_conflict`,
  `rebase_abort`, `push`, `push_retry`, ...); a rebase that never started is not aborted. When the same step keeps failing
  until the push backoff reaches its 5-minute cap, `dag run` exits 20 with git's error and repair commands.
- No new configuration; existing JSON fields and exit codes are unchanged.
