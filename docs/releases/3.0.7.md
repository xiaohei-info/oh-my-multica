# oh-my-multica v3.0.7

## Behavior to know

- **`omac node retry --answer "<text>"`** answers an open Worker blocker. The answer is bound to the blocker's `handoff_generation`,
  shown to the Worker as `work show` `control.owner_answer`, and posted as an issue comment. `--answer` replaces `--note` and applies
  to the authoring stage.
- The Worker guide now states that an owner answer is a decision to execute, not a reason to block again.

## Install

```bash
pipx install oh-my-multica==3.0.7
```
