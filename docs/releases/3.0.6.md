# oh-my-multica v3.0.6

## Behavior to know

- **Upstream defect reruns are gated on fix recency.** A new fingerprint is rerun against a merged fix of the same node only when
  that fix was merged after the reporter's newest Run started; an older fix gets a new fix node instead.
- **`defects.per_suspected` (default 2)** caps automatic fixes of one node (`defect-node-fix-cap`).
- **New `omac defect resolve`** records a fix merged outside OMAC.
- CI: the Multica CLI downloads retry on transient GitHub Release errors.

pipx install oh-my-multica==3.0.6
