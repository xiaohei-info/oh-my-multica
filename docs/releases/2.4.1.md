# oh-my-multica v2.4.1

A fix release: an operator decision now leaves no stale recovery facts behind.

## Behavior to know

- **`omac node accept` / `omac node abandon` retire the decision they answer.** `decision_required` and `worker_handoff` on
  the node's WorkItem are cleared and the node's `recovery_marker` is reset. Previously a node accepted after a manual PR
  merge could stay `done` with a leftover handoff or decision, and the next `dag run` stopped at reconcile with
  "Confirmed merge node ... still has recovery control facts".
- **Already stuck?** Run `omac node accept <manifest> <node>` again on the done node (its PR is merged); the error message now
  says so.
- No new configuration; existing JSON fields and exit codes are unchanged.
