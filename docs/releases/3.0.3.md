# oh-my-multica v3.0.3

A fix release for Reviewer recovery.

## Behavior to know

- **`omac node retry <manifest> <node> --stage review` now clears a `reviewer-run-no-submit-retry-exhausted` or
  `reviewer-run-terminal-time-unavailable` block.** Before, the command was refused as "the persisted recovery decision does
  not identify this review" although it was the `next_action` OMAC advertised.
- No new configuration; JSON fields and exit codes are unchanged.

## Install

```bash
pipx install oh-my-multica==3.0.3
```
