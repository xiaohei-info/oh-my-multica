# oh-my-multica v3.0.2

A fix release for the upstream-defect loop.

## Behavior to know

- **A person's `omac defect report` for a node blocked on another worker decision gets its fix node.** Before, the system
  amendment refused the node and the report stopped as `defect-unroutable`.
- **Every defect stop records its reason** in the ledger entry (`stop.reason_code`, `stop.detail`, shown by
  `omac defect list`) and in the blocked reporter's `decision_required`.
- **A stopped report is logged once.** Release it with `omac defect grant` or a new `omac defect report`.
- No new configuration; existing JSON fields (only additions) and exit codes are unchanged.

## Install

```bash
pipx install oh-my-multica==3.0.2
```
