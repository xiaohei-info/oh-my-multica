# oh-my-multica v2.0.1

A patch release for planning from an existing design.

## Fixed

- **Large `--doc` sources.** `omac plan create --doc` and `omac plan resume --doc` failed on a design file or directory
  source over 64 KiB because no upstream issue carried it. OMAC now publishes every `--doc` source as the deliverable of a
  finished source issue (`doc-<plan-id>`, no Agent assigned). Later stages reference that issue and read the source with
  `omac work read`, as they do for a planner's design.
- A Run created in the same second as the cutoff is no longer treated as history.

## Behavior to know

- Each `--doc` run now creates one more issue on the platform, and `meta.source_issues` lists it first.
- `plan resume --doc` reuses that issue. If the document changed, OMAC publishes the new version; a stage still bound to
  the old digest refuses to read it until it is refreshed with `--restart-active`.

pipx install git+https://github.com/xiaohei-info/oh-my-multica.git@v2.0.1
